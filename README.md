# Forja Studio

Projeto independente de criação visual de cenas, separado do Aurora Engine.

## Publicar
No GitHub: Settings → Pages → Deploy from a branch → main → /(root). O GitHub mostrará a URL publicada.

## Primeira versão
Interface própria, visualização 2D Canvas e 3D com Three.js, hierarquia, inspetor, ferramentas básicas, construção por IA usando o Worker existente da Aurora, salvamento local e exportação JSON.

## Limites
Personagens são modelos visuais básicos. Rigging, timeline avançada, terreno esculpível e execução segura de scripts ainda precisam ser desenvolvidos. A visualização 3D carrega Three.js por CDN e requer internet.
